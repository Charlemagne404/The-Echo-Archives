# Submit page icon sources

`images/submit-icons.svg` is a local sprite assembled from the following upstream SVGs on 2026-10-08. Pages load the bundled file locally and do not request icons from a CDN.

- Interface icons: [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons), ISC license with the Feather MIT notice where applicable. The upstream license text is kept in `LUCIDE-LICENSE.txt`.
- Service marks: Spotify, Apple Podcasts, and YouTube from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), with official brand colors from its icon metadata. The upstream license text is kept in `SIMPLE-ICONS-LICENSE.txt`.

The Lucide symbols used in the sprite are `radio-tower`, `file-pen-line`, `star`, `badge-check`, `pencil-line`, `message-square-text`, `message-square`, `shield-check`, `file-text`, `clipboard-list`, `info`, `circle-question-mark`, `search`, `check`, `x`, `plus`, `chevron-down`, `arrow-right`, `clock`, `archive`, `link-2`, `rss`, `globe`, `users-round`, `award`, `tag`, `sparkles`, `image`, `circle`, `send`, `clipboard-check`, `scale`, and `messages-square`.

The brand glyphs identify the matching listening destination only. Simple Icons notes that its artwork license does not grant trademark rights; see its [legal disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md) and each brand's current usage guidance before changing how these marks are used.
