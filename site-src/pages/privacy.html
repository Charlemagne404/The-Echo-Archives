What the site stores in your browser

The Ask the Archivist panel keeps recent conversation history in session storage so it survives page refreshes during the same browser session.

Anonymous community ratings use local storage to keep a generated profile identifier on your device. That lets the same browser update or remove its own rating later without requiring an account.

What the server receives

When you submit a rating, correction, listener review, creator verification request, or new-show submission, the server receives the request body you send.

  • Limited technical data such as IP address and user agent may be used for moderation, abuse prevention, and rate limiting.
  • Submission content is reviewed before it affects the public archive.
  • The site does not currently run public analytics or advertising trackers.

Submissions and contact details

If you send a submission form with a contact email, that email is stored with the submission so the maintainer can review the request or follow up when necessary.

Do not send private information that is not relevant to the archive entry, correction, review, or verification request.

Cookies and maintainer access

Public browsing, chat, and anonymous community ratings do not currently require first-party cookies. The private maintainer review area may set an HTTP-only session cookie when maintainer authentication is enabled.

See the cookies and browser storage page for the practical storage list.

Third-party services and changes

The site links out to external listening platforms, official show sites, Patreon, GitHub, and other destinations chosen by the user. Those services operate under their own privacy terms once you leave The Echo Archives.

If the archive adds accounts, analytics, newsletters, or other personal-data features later, this page should be revised to match the live behavior instead of relying on boilerplate policy text.
