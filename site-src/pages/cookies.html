Cookies and browser storage

The site currently relies on browser storage more than cookies. This page reflects the current implementation and should stay specific.

First-party cookies

The Echo Archives does not currently set first-party application cookies for chat, anonymous community ratings, or basic catalog browsing.

Session storage

The Ask the Archivist panel stores recent chat history in session storage under a browser-scoped key so the conversation can survive reloads during the same session.

Local storage

Anonymous community rating flows store a generated profile identifier in local storage so the same browser can update or remove its own rating later without a required account.

Future changes

If analytics, authentication, or preference cookies are introduced later, this page should be updated with the cookie purpose, duration, and whether the cookie is required or optional.
