Cookies and browser storage

The site currently relies on browser storage more than cookies. This page lists what is used today and what each item supports.

Back to previous page Privacy summary

Public browsing

Basic browsing and chat do not need first-party application cookies.

Session storage

Ask the Archivist keeps recent chat history during the current browser session.

Rating cookie

Community ratings use an anonymous HTTP-only voter cookie so one device keeps one active vote per show.

Public archive features are designed to work without account cookies.

First-party cookies

The Echo Archives does not currently set first-party application cookies for basic catalog browsing or public chat.

Session storage

The Ask the Archivist panel stores recent chat history in session storage under a browser-scoped key so the conversation can survive reloads during the same session.

Session storage is cleared by the browser when the session ends or when the user clears site data.

Local storage

The Ask the Archivist and maintainer review interfaces may use local browser storage for interface continuity, such as recent chat state or a reviewer display name.

Community rating authority no longer depends on a local-storage profile identifier.

Community rating cookie

Community ratings use an HTTP-only cookie named echo-community-voter by default. It stores a random device token in the browser, while the server stores only a salted hash of that token.

The cookie is used only to let one device update or remove one active vote per show without requiring an account. Rating writes may also require Cloudflare Turnstile verification.

Maintainer session cookie

The private maintainer review area may set an HTTP-only session cookie named by the server configuration. Its default name is echo-maintainer-session.

This cookie is used only for maintainer authentication, uses SameSite=Lax, and is not used for public browsing or advertising.

Future changes

If analytics, authentication, or preference cookies are introduced later, this page should be updated with the cookie purpose, duration, and whether the cookie is required or optional.

The privacy page should be updated at the same time so the two pages stay aligned.
