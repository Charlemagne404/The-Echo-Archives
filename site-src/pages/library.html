Your local copy

Backup and restore

Export and import Library entries as readable JSON using the the-echo-archives.listener-library format (schema version 1). The file contains local Library data such as states, private ratings, timestamps, and saved title snapshots. It never includes your Personal Discovery choice. Anyone who can read the file can see its contents.

Export a backup

Download the current entries, current states, private ratings, and title snapshots for unresolved shows. The backup stays on your device until you choose where to save it.

Import a backup

Choose a backup to validate and preview it. Nothing changes until you select Merge or confirm Replace.

Import mode

Merge keeps local-only entries. If an ID exists in both files, the imported full record replaces the local record after preview. Replace makes imported entries the complete Library after a separate confirmation. Both modes leave Personal Discovery unchanged.

Backup preview

Trouble opening this Library?

A raw recovery file can help preserve rows if stored data is malformed. It is not a normal Library backup and cannot be imported as one. It may contain unprocessed local settings as well as entries; keep the file private.

Replace Library

Replace every current entry?

This will remove all current Library entries and install the entries in the validated backup. Your Personal Discovery setting will stay as it is. This cannot be undone unless you have another backup.
