# Security Policy

## Supported deployment

The current maintained deployment is the live `echo.continental-hub.com` site
and the current default branch of this repository.

## Reporting a vulnerability

Do not post exploit details in a public issue or discussion.

Report security issues privately to the maintainer through the contact route
linked on the site or the maintainer profile linked in the footer:

- `/contact.html`
- [https://github.com/Charlemagne404](https://github.com/Charlemagne404)

Include:

- A short description of the issue
- Reproduction steps
- Impact assessment
- Any suggested fix or mitigation

The goal is to acknowledge credible reports promptly, confirm severity, and
ship a fix before public disclosure where practical.
