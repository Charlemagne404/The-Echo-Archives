# Echo Archives 1.1.0 — Creators

Local implementation and validation, refreshed 2026-09-06. This is not deployment evidence.

## Released behavior

- Curated `/creators` directory with 40 organization cards and 42 stable
  `/creators/<id>` catalogues (the two person records remain available through
  the existing entity architecture), rendered by the static build and Node
  server.
- Desktop navigation: Browse, Collections, Creators, About, Submit, For creators.
  Mobile shortcuts: Browse, Collections, Creators, Submit. About remains in the menu.
- Explicit linked show facts, one deterministic More from section when at least
  three other confirmed shows exist, and creator results in existing Browse search.
- Canonical metadata, breadcrumbs, Person/Organization structured data, show
  references and publication-gated sitemap entries. Aliases create no routes.
- Authored registry, build-time relationship validation and maintainer documentation
  in [CREATORS.md](../CREATORS.md).
- Follow-up maintenance fixes cover responsive mobile controls, public hero sizing,
  similarity pagination, CSS structure hard limits, canonical format/theme values,
  and the unsafe image parser dependency.

The public release marker follows the existing footer version convention and is
now v1.1.0. The backend package's independent 2.0.0 version is unchanged.

## Curation and preservation

The authored registry now contains 42 public entities: 40 organization-level
directory entries and two people retained internally with `directory: false`.
They connect 172 published shows through 187 explicit typed relationships.

The full organization registry and per-show relationship counts are documented
in [CREATORS.md](../CREATORS.md). The original seven pilot records remain
represented: five organizations are public directory entries, while K.A. Statz
and Travis Vengroff remain separate person entities and show-level creators.

Atlas Avenue Beat belongs to both 7 Lamb and Bloody FM despite its compound legacy
creator ID. The White Vault and Vast Horizon retain separate individual creator
links and Fool & Scholar production-company links. Night Vale Presents uses its
explicit production-company role on Welcome to Night Vale and network roles on
Within the Wires and Dreamboy.

The curation added explicit organization relationships to 155 previously
unlinked published shows. Existing authored metadata, reviews, verification
states, collection memberships and submission purposes were preserved. Compound
legacy values are retained in their source fields but are split into explicit
relationships where verified. ART19, Buzzsprout, RSS.com, Spreaker and other
hosting/distribution labels have no entity pages.

The catalog still contains 724 shows and 46 collections. Unrelated Finder
`.DS_Store` changes and other pre-existing working-tree changes were preserved.

## Resolved verification issues

The maintenance pass resolved the issues found during the launch audit:

- mobile browse modes are visible and usable at touch widths without creating
  horizontal overflow;
- public hero padding is consistent across compact information pages;
- similarity collection smoke coverage follows the actual five-at-a-time
  reveal contract through the final page;
- the responsive and entity CSS bundles are split at the existing hard structure
  limit without weakening the check;
- authored format and theme values no longer create duplicate case-only filter
  concepts;
- the unused vulnerable `image-size` parser was removed in favor of the existing
  `sharp` dependency, while ICNS/JXL/HEIF rejection remains explicit.

The final repository verification is green. Remaining structure output is
non-blocking soft warnings for intentionally large shared modules and existing
cover assets.

   available. There are no generated biographies.
3. Verify live deployment, source reachability, provider behavior, recovery, and
