# Security invariants and trust boundaries

This document maps security and privacy claims to the code that enforces them and the tests that exercise them. These are implementation invariants, not a claim that production infrastructure was independently inspected. The 2026-09-30 adversarial review and its limits are recorded in [2026-09-30-security-redteam.md](2026-09-30-security-redteam.md).

## Operational boundary

`backend/server.js:560` applies the configured Express `TRUST_PROXY` setting. The production deployment must set that to match only its actual trusted proxy topology so attacker-supplied forwarding headers cannot choose the client IP used for throttling or audit pseudonyms. The application source emits CSP, frame, MIME-sniffing, referrer, permissions, and cache headers, but no HSTS header in this middleware. The external TLS/CDN layer was not inspected in this local review; its forwarding and HSTS policy remain deployment evidence requirements.
