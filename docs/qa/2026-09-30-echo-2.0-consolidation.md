## Semantic conflict resolutions

- **Library UI and privacy:** kept the snapshot's compact contextual card and show-detail controls, browser-local IndexedDB model, five states, private rating, opt-in Personal Discovery, and no `/library` route. Merged smoke assertions verify both the controls and the absence of the route/navigation surface.
- **Generated runtime files:** rebuilt `script.js` and `sw.js` from source instead of choosing stale generated copies. The resulting worker keeps policy version 2, `no-store` exclusions, API cache bypass, and 502/503/504 navigation fallback.
- **Smoke inventory:** combined the later browser tests with the test-quality fail-closed inventory and serial enumeration. Each smoke file has one runner assignment; missing assignments fail instead of silently producing a partial green run.
- **Runtime and persistence:** retained both the early Node-API guard and malformed-persistence fail-closed behavior where runtime and security work overlapped.
- **Duplicate static-root helper:** kept the existing visible-static-root alias used by callers and did not carry a redundant `helpers/static-root.js` implementation.
- **Discovery benchmark fingerprint:** an untracked `.DS_Store` on the original machine had contaminated the catalogue fingerprint. The benchmark now excludes `.DS_Store` and AppleDouble metadata; authored files and all 57 frozen observations remain unchanged.

## Reconciliation fixes
