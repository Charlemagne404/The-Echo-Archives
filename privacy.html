Privacy

The Echo Archives keeps the data footprint small. This page describes what the site stores today and what it does not.

What the site stores in your browser

The chat panel keeps recent conversation history in session storage so it survives page refreshes during the same browser session. Anonymous community ratings use local storage to keep a generated profile identifier on your device so the site can associate your own rating with the same browser later.

What the server receives

When you submit a rating, correction, creator verification request, or new-show submission, the server receives the request body you send along with limited technical data such as IP address and user agent for moderation, abuse prevention, and rate limiting.

Submissions and contact details

If you send a submission form with a contact email, that email is stored with the submission so the maintainer can review the request or follow up when necessary. Do not send private information that is not relevant to the archive.

Cookies

The site does not currently set first-party application cookies for chat, ratings, or basic browsing. If that changes, this page and the cookies page should be updated alongside the implementation.

Third-party services

The site links out to external listening platforms, official show sites, Patreon, GitHub, and other destinations chosen by the user. Those services operate under their own privacy terms once you leave The Echo Archives.

Changes

If the archive adds accounts, analytics, newsletters, or other personal-data features later, this page should be revised to match the live behavior instead of relying on boilerplate policy text.
